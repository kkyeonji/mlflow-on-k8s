# mlflow-on-k8s

Deploying MLflow on Kubernetes using Helm, with PyTorch training jobs integrated for automated experiment tracking.

## Overview

This project demonstrates how to:
- Deploy MLflow on a Kubernetes cluster using Helm
- Run PyTorch training jobs as Kubernetes Jobs
- Track experiments automatically via MLflow Tracking URI injection
